# K24 Digital Studio — V2

Преміальний адаптивний сайт K24 Digital Studio. Стек: HTML5, CSS3, vanilla JavaScript. Збірка та серверна частина не потрібні.

## Файли
- `index.html` — структура, тексти та SEO-метадані.
- `styles.css` — дизайн, адаптивність, анімації.
- `script.js` — мобільна навігація, анімації появи, поточний рік.
- `assets/favicon.svg` — іконка сайту.

## Запуск
Відкрийте `index.html` у браузері. Для локального сервера можна використати VS Code Live Server або команду `python -m http.server` у папці проєкту.

## Публікація на GitHub Pages
1. Завантажте файли та папку `assets` у корінь репозиторію `vladosik24/K24`.
2. Переконайтеся, що `index.html` лежить у корені гілки `main`.
3. У GitHub відкрийте Settings → Pages.
4. У Build and deployment виберіть Deploy from a branch → `main` → `/ (root)` → Save.
5. Після публікації відкрийте `https://vladosik24.github.io/K24/`.
